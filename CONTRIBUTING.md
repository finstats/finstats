# Contributing to FinStats

Thanks for wanting to help. The whole guide (what fits the project, reporting a bug, suggesting a feature, running
FinStats from source or in a local Docker setup, the rules for a change, commit messages and pull requests) is on the
documentation site:

**[docs.finstats.no/finstats/contributing](https://docs.finstats.no/finstats/contributing/)**

The short version:

- A question about installing or running FinStats belongs in
  [Discussions → Q&A](https://github.com/finstats/finstats/discussions/categories/q-a), not in an issue.
- For anything bigger than a bug fix, **talk before you build**: open a
  [feature request](https://github.com/finstats/finstats/issues/new?template=feature_request.yml) or think out loud in
  [Discussions → Ideas](https://github.com/finstats/finstats/discussions/categories/ideas).
- A vulnerability is reported privately; see [`SECURITY.md`](SECURITY.md).
- **Never attach** `finstats.db`, a backup or a tracker export, and blur names, titles and addresses in logs and
  screenshots. Code, tests, docs and commit messages use invented data only.
- Documentation lives in [its own repository](https://github.com/finstats/docs): a change that a page describes comes
  with a pull request there too.
- Everyone taking part follows the [code of conduct](CODE_OF_CONDUCT.md). By contributing you agree that your
  contribution is licensed under the [GNU General Public License v3.0](LICENSE).
